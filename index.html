Sincronización en la Nube (Supabase)

Conecta la aplicación a Supabase para sincronizar tus datos con tu pareja en tiempo real.

Estado: Modo Local (Sin nube)

Configuración requerida en Supabase:

Crea una tabla en tu SQL Editor ejecutando el siguiente comando: 

CREATE TABLE IF NOT EXISTS public.duet_budget (
  id text PRIMARY KEY,
  data jsonb NOT NULL,
  updated_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);
ALTER TABLE public.duet_budget REPLICA IDENTITY FULL;
ALTER PUBLICATION supabase_realtime ADD TABLE public.duet_budget;

⚖️ Conflicto de Datos en la Nube

Se ha detectado un presupuesto guardado en la nube que difiere de tus datos locales.

¿Cómo deseas resolver este conflicto para sincronizar?

Opción A: Descargar datos de la nube Reemplaza tu presupuesto local con el de la nube. Elige esto si tu pareja ya cargó los datos actualizados.
Opción B: Subir datos locales a la nube Sobrescribirá la nube con tus datos locales. Elige esto si estás haciendo la primera configuración.
